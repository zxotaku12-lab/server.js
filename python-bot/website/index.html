    Setup — 4 steps

    Python 3.11+ chahiye. Har command copy kar sakte ho.

    1. Clone & install

      cd python-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

    2. Config bharo

      cp .env.example .env
# TOKEN=...            (Developer Portal → Bot → Reset Token)
# GOGETAS_PET_OWNER_ID=...   (apna user ID)
# DISCORD_GUILD_ID=...       (test server ID, optional)

      ⚠️ .env gitignored hai. Token kabhi commit/chat me nahi.

    3. Preflight

      python check_deploy.py   # token + files verify, secrets print nahi karta

    4. Commands register karo & bot chalao

      python scripts/sync_commands.py --guild $DISCORD_GUILD_ID   # instant
python bot.py                                               # startup pe khud sync
